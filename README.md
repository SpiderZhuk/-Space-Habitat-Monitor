# -Space-Habitat-Monitor
`Space Habitat Monitor is an open-source ESP32-based device for monitoring environmental conditions in a simulated space habitat. It monitors parameters such as temperature, humidity, pressure, and acceleration, and also features a built-in gyroscope. This project is named "Space Habitat Monitor" because I configured it to track data for rockets, the ISS and similar environments using official NASA data. However, since the source code is open, you can easily modify the settings in just a minute.`

# Technical Part

## BMP180 Barometric Pressure Sensor

*Barometric pressure and temperature sensor with I2C interface.*

#### Measurement ranges
Temperature: -40°C to 85°C
Pressure: 30000 Pa to 110000 Pa (300 hPa to 1100 hPa)
The default pressure value of 101325 Pa corresponds to standard sea level atmospheric pressure (1 atm).

## MPU6050 Accel & Gyro Sensor

*Integrated sensor with 3-axis accelerometer, 3-axis gyroscope and a temperature sensor with I2C interface.*

#### Units
All the acceleration values (x/y/z) use g-force units, where 1g = 9.80665 m/s². The gyroscope measures angular rotation and returns the number of degrees per second.
