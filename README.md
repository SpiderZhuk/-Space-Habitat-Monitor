# -Space-Habitat-Monitor
Space Habitat Monitor is an open-source ESP32-based device for monitoring environmental conditions in a simulated space habitat. It monitors parameters such as temperature, humidity, pressure, and acceleration, and also features a built-in gyroscope. This project is named "Space Habitat Monitor" because I configured it to track data for rockets, the ISS and similar environments using official NASA data. However, since the source code is open, you can easily modify the settings in just a minute.
